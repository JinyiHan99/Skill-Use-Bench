# Partner Center listing copy

Short description: Find partner directory records for account teams.

Long description: This plugin helps account teams search partner companies and open the relevant partner profile from Copilot. The search result should make clear that data comes from the partner directory and that records may be subject to regional availability.

Suggested user prompts:
- Find partners for a manufacturing customer in Germany.
- Show partner records related to Teams adoption.
- Open the partner profile for a named company.
