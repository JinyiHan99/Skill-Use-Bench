# Source brief: Selenium39/todo-app-vercel

Source: https://github.com/Selenium39/todo-app-vercel
Fetched: 2026-07-01

This repository is described as a simple to-do application built with Next.js and Supabase. The public README lists these capabilities:

- Add new to-do items
- Mark to-do items as completed
- Delete to-do items
- Group and archive completed to-do items by day
- Store data with a backend database
- Generate weekly reports with AI

The visible repository structure includes `pages/`, `public/`, `styles/`, `.gitignore`, `README.md`, `next.config.js`, `package.json`, and `tsconfig.json`.

The README states that the project uses Next.js, Chakra UI, Supabase, Day.js, and React Markdown, and that the project is licensed under MIT.
