# Source brief: GoogleChrome chrome-extensions-samples readingList

Source: https://github.com/GoogleChrome/chrome-extensions-samples/tree/main/api-samples/readingList
Fetched: 2026-07-01

This sample demonstrates an extension for viewing items in a browser reading list. Its README says the action icon opens a page that lets a user add new items and update or delete existing ones.

The visible sample files are:

- `README.md`
- `index.css`
- `index.html`
- `index.js`
- `manifest.json`
- `screenshot.png`

The README also notes that listeners are added for all events so the table updates automatically when data in the reading list changes.
