# PyCon China 2024 公开活动素材摘录

来源：PyCon China 2024 官网首页 https://cn.pycon.org/2024/ 与日程页 https://cn.pycon.org/2024/schedule/
获取方式：从公开网页提取活动事实信息，保留原始中文标题与日程要点。

## 活动概况

- 活动名称：PyCon China 2024
- 时间：2024/11/23
- 城市：上海
- 会议说明：PyCon China（中国 Python 开发者大会）自 2011 年首届大会起，每年由 PyChina 社区定期举办，现如今已成为中国大型的 Python 技术会议。
- 大会定位：汇集来自整个 Python 生态的开发者和技术专家，交流 Python 技术，包括语言特性、开源项目、工程实践、运维测试、性能优化、创新应用等多个方面。
- 2024 主题表述：邀请全国的 Pythonistas 齐聚上海，不限领域、不限主题，欢迎所有与 Python 相关的话题，来一场“Just for Fun”的大 Party。
