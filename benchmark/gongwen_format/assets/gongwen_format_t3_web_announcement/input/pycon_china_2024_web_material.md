## 基本信息

PyCon China 2024 于 2024 年 11 月 23 日在上海举办。PyCon China（中国 Python 开发者大会）自 2011 年首届大会起，每年由 PyChina 社区定期举办，现如今已成为中国大型的 Python 技术会议。大会汇集来自 Python 生态的开发者和技术专家，交流语言特性、开源项目、工程实践、运维测试、性能优化、创新应用等多个方面。
