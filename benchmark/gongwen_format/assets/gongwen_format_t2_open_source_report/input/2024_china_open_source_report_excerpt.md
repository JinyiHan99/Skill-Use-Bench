# 2024 中国开源年度报告公开摘录

来源：开源社《2024 中国开源年度报告》数据篇 https://kaiyuanshe.github.io/2024-China-Open-Source-Report/data.html
获取方式：从公开报告页面摘录结构与指标信息，保留原始中文表述与公开数据。

## 报告定位

《2024 中国开源年度报告》以全面、深入的数据洞察为核心，通过九大篇章全方位展现中国开源生态的发展，为行业提供洞察与参考。

## 九大篇章

1. 宏观洞察篇：基础事件、活跃仓库、活跃用户、编程语言。
2. OpenRank 排行榜篇：全球与中国项目、企业、基金会、开发者及协作机器人排名。
3. 企业洞察篇：全球与中国企业战略布局与演化路径。
4. 基金会洞察篇：基金会动态演变与趋势分析。
5. 技术领域洞察篇：各领域 Top10 榜单与项目变化。
6. 开源项目洞察篇：项目类型、领域与主题多样性。
7. 开发者洞察篇：开发者类型、工作时间分布、地区分布及机器人使用。
8. 商业开源洞察篇：商业开源企业与项目发展现状。
9. 高校开源洞察篇：高校学生参与开源活动的活跃度与贡献度。

## 核心指标说明

- OpenRank：X-lab 开放实验室研发，基于开发者-项目协作关系网络，评估项目影响力与开发者贡献度，可聚合至企业、组织、基金会层级。
- Activity：量化评估项目或开发者活跃程度，基于 Issue 提交、PR 创建、代码 Review 等行为加权计算。

## 关键发现

- 2024 年 GitHub 全域事件日志总数达 17.5 亿，同比增长约 10%。
- Gitee 事件数量稳步上升，Review Comment 事件占比 75.6%。
- GitHub 2024 年活跃开发者 2,511 万，增长率回升至 14.1%。
- 全球开发者前五：美国 17.11%、印度 9.91%、中国 7.23%、巴西 6.87%、德国 4.96%。
- 中国开发者总量 9,404,966 人，增长率 6.11%。
- 中国开发者分布：北京 22.04%、上海 16.43%、广东 14.49%，前三合计超过 50%。
- 编程语言 Top 5：JavaScript 591,223 开发者；Python 540,751；TypeScript 439,954；HTML 424,901；Java 281,403。
- 技术领域方面：云原生优势明显，AI 增速显著，数据库稳居前列，前端影响力逐年降低。
- 生成式 AI 方面：2024 年 AIGC 全域发展进入放缓期，工具类项目影响力显著高于模型类和应用类。

## 内部汇报背景

技术战略办公室准备向管理层提交一份年度开源生态观察材料，重点用于判断研发平台、AI 工具链、数据库与开发者生态建设方向。材料需要压缩为正式汇报文稿，便于归档和流转。
