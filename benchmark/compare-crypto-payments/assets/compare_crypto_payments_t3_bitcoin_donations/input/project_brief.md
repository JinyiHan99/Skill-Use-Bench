# Source packet: open-source Bitcoin donation/payment processor decision

This packet contains excerpts gathered from public project/vendor pages on 2026-07-02.

## Organization brief

The organization runs a public-interest software project. The team currently receives international donations and wants a payment option for Bitcoin supporters. The finance lead prefers infrastructure that can be run by the organization or a trusted community host. The current donor community overwhelmingly asks for BTC invoices and payment links; stablecoin support is not a launch requirement.

## BTCPay Server public page
Source: https://btcpayserver.org/

- BTCPay Server says: "Start Accepting Bitcoin Payments With 0% Fees & No Third-party."
- It describes itself as "a self-hosted, open-source cryptocurrency payment processor."
- It is "secure, private, censorship-resistant, and free."
- Users can launch a server in the cloud, on their own hardware device, or use an existing host.
- Funds arrive directly to the connected wallet.
- Built-in apps include Point of Sale, tipping button, payment link, crowdfunding campaign, invoicing, and accounting exports.
- BTCPay includes native wallet management with hardware wallet support.
- Users can self-host or use a shared server.
- It offers automation via API for stores, invoices, users, workflows, and access control.

## PayRam docs
Source: https://docs.payram.com/

- PayRam is described as a self-hosted PayFi platform for stablecoin and cryptocurrency payments.
- It emphasizes stablecoin payments, no middlemen, full custody, full data/control, and deployment on user-controlled infrastructure.
- The docs say agents can use a hosted MCP server and that there is no signup or KYC.

## NOWPayments public page
Source: https://nowpayments.io/

- NOWPayments advertises 350+ crypto coins and 75+ fiat coins.
- It offers invoices, donation tools, payment buttons, APIs, plugins, widgets, and other hosted payment products.
- Its FAQ says merchants sign up and create an API key.
- It charges 0.5% for mono-currency payments and 1% for payments with conversion, excluding network fees.

## BitPay business page
Source: https://www.bitpay.com/business/

- BitPay supports Bitcoin, Ethereum, Solana, stablecoins like USDC, and more.
- It can settle in fiat direct to a bank account so merchants do not need to hold crypto.
- It offers crypto invoicing and e-commerce integrations.
- It is licensed and regulated, with KYC, AML, and transaction monitoring.
